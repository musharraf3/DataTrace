# Three-minute demonstration

This script uses implemented local functionality. Live Meta mode must pass an
authenticated acceptance run before recording a demo described as AI-powered.
Offline mode must be identified as deterministic contract diagnostics.

## Preparation

1. Install and run using README. Add the key privately if using live inference.
2. Open the default example, Revenue incident 01 with data variant 2.
3. Confirm no secrets, personal data, or employer records appear on screen.
4. Open the completed evaluation JSON in advance. Use only results actually run.

## Recording timeline

| Time | Demonstration |
| --- | --- |
| 0:00–0:20 | Analysts need to know whether a changed dashboard metric reflects real growth or a calculation defect. Introduce DataTrace and its narrow supported contract. |
| 0:20–1:15 | Click Investigate metric change. Follow the revenue bridge from $1,200 to $1,700. Point out the $100 underlying change and the $400 reporting error. The affected-orders table shows the order whose reported row count doubled. |
| 1:15–1:40 | Show the verified corrected revenue of $1,300. Open Execution evidence to show the four-way replay, or open Verify a correction to test the candidate SQL. |
| 1:40–2:00 | Run incident 02: legitimate growth should remain, with no unnecessary correction. |
| 2:00–2:20 | Run incident 03: refund treatment is missing, so DataTrace requests clarification. |
| 2:20–2:40 | Inspect per-order verification and download the Markdown/JSON evidence. Briefly show custom incident import and editable contract. |
| 2:40–3:00 | Explain Meta tool calls, SQL boundaries, and actual evaluation results. State what was built during the event and what remains unverified. |
